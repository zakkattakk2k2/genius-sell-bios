    1 · Import tutor photos

    Select every photo in your Staff Photos folder at once. Filenames are parsed automatically — Resized is preferred over Full, brand tags (GI / EL / GPL) and stray punctuation are stripped, and duplicates collapse to one tutor. Photos are downscaled in your browser before upload, so nothing huge is stored. Existing bios are never overwritten by this step.

    2 · Import sell bios from Excel

    First column = tutor name, second column = bio. A header row is detected and skipped. Names are matched to existing tutors; anything unmatched is listed rather than silently dropped, and nothing is written until you confirm.

    3 · Who can upload

    This is the same list the Firestore security rules read, so the button and the permission can never disagree. Only you can edit it.
