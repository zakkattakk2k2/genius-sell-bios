    1 · Import tutor photos

    Select every photo in your Staff Photos folder at once. Filenames are parsed automatically — Resized is preferred over Full, brand tags (GI / EL / GPL) and stray punctuation are stripped, and duplicates collapse to one tutor. Photos are downscaled in your browser before upload, so nothing huge is stored. Existing bios are never overwritten by this step.

    2 · Import sell bios from Excel

    First column = tutor name, second column = bio. A header row is detected and skipped. Rows whose name matches a tutor exactly are written straight through. Everything else lands in a review list with the closest names offered, so a bio filed under Thato Mashiyane can still be attached to a photo saved as Thato. Nothing is written until you confirm.

    3 · Add a tutor by hand

    For someone with no photo file — or whose photo never imported. You can add the photo now or later. To change an existing tutor instead, use the Edit button on their row in Send or View All.

    4 · Who can upload

    This is the same list the Firestore security rules read, so the button and the permission can never disagree. Only you can edit it.
